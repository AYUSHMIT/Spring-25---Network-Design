How to Run
1.	Install Dependencies:
Ensure you have Python 3 installed and then install PyQt6:
    pip install PyQt6


2.	Save the Files:
    Save the three files gui.py, server.py, and client.py—in the same directory.

3.	Run the Server:
    Open a terminal, navigate to the directory, and execute:
    python3 server.py

4.	Run the Client:
In another terminal, navigate to the same directory and execute:
    python3 client.py image.jpg
